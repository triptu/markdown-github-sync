Syncs an Obsidian vault between your computer and your phone through a GitHub repository you own. Every sync is a plain commit. No server, no Git on your device.

Twenty-two seconds, recorded in Obsidian and Notes for Android with made-up notes.

Every sync is a commit.

Each device commits its own changes. The history is plain Git, so you can browse it on GitHub and restore an old version of any note.

Two edits, one note.

Changes to different files, or different parts of a note, merge on their own. When two devices change the same lines, you pick.

Quiet when it works.

A good sync shows in the status bar and nowhere else. A problem shows one notice, which clears itself once sync recovers.

Set it up once per device.

  1. Install Gitless Vault Sync from Obsidian's community plugins: Settings → Community plugins → Browse, then search for it.
  2. Make a repository on GitHub, then turn on the plugin.
  3. Enter the repository and a token in the plugin's settings, click Connect, look over the first sync, and start.

The README has the full steps and the token permissions.

Beta. GitHub only. Needs Obsidian 1.11.4 or newer.

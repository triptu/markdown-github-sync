GitHub Vault Sync syncs an Obsidian vault between your computer and your phone through a private GitHub repository you own. Every sync is an ordinary commit, sent straight to the GitHub API. There's no server, and no Git on your device.

History

Every sync is a commit.

Each device commits its own changes to your repository. The history is plain Git, so you can browse it on GitHub like any other repo.

  • File history previews a note's past versions and restores the one you pick.
  • Sync history lists every sync from every device.
  • Name each device and shape the commit message in settings.

Merging

Two edits, one note.

Edits to different files, or to different parts of the same note, merge on their own. When two devices change the same lines, you choose.

  • The conflict view shows a line diff of this device's version against GitHub's, and gives it most of the screen.
  • Keep either one, keep both, or edit a combined version.
  • Large deletions wait for you to confirm before they reach the other side.

Status

Quiet when it works.

A sync that goes well says so in the status bar and nowhere else. No toasts, no spinners over your note.

  • Being offline shows only in the status bar. After 6 hours without a sync, it becomes a notice.
  • A problem with the token or the repository opens settings.
  • Anything else shows one notice, which clears itself once sync recovers.

When it syncs

Made for a phone.

Sync runs while Obsidian is open, and is built to stay light on a phone. A sync with nothing to send takes about three seconds, most of it waiting on the network.

  • 30 seconds after you stop typing, and at most 2 minutes after the first edit.
  • When you leave Obsidian, and when you come back. Every 5 minutes otherwise.
  • Themes, hotkeys and plugins sync too. Incoming changes to them wait until you review them on each device.

Updates

Updates itself, carefully.

A small companion plugin, GitHub Vault Sync Updater, keeps the main plugin current on every device. It needs no token.

  • It checks about every 6 hours. Run Check for GitHub Vault Sync update from the command palette to check now.
  • Each file is checked against its SHA-256 before it's installed.
  • If a new version fails to load, the updater puts the old one back and skips that version.

On Android

Pairs with Notes.

Obsidian on a phone works fine with this plugin. If you'd rather have something smaller, Notes for Android opens straight to your pinned notes and runs this plugin's sync engine, unchanged.

  • Same private repository, same commits, same conflict handling.
  • Write on the phone, open Obsidian on your computer, and the note is there.

Install

Set it up once per device.

Install both plugins from the latest GitHub release. After that, the updater keeps the sync plugin current.

  1. Download both plugins.

    Get github-vault-sync.zip and github-vault-sync-updater.zip from the latest release, and unzip both into your vault's .obsidian/plugins/ folder. On a phone, copy the two folders over with USB or a file manager. With the GitHub CLI, from your vault folder:

    mkdir -p .obsidian/plugins && cd .obsidian/plugins \
  && gh release download -R triptu/markdown-github-sync -p '*.zip' --clobber \
  && unzip -oq github-vault-sync.zip && unzip -oq github-vault-sync-updater.zip \
  && rm github-vault-sync*.zip
  2. Make a private repository.

    Create one on GitHub, for example your-name/notes. Tick Add a README file, because it can't be empty.

  3. Turn the plugins on.

    In Settings, Community plugins, turn off any other sync plugin. Then enable GitHub Vault Sync and GitHub Vault Sync Updater.

  4. Add the repository and a token.

    Enter the repository and branch. The Create token link opens GitHub's fine-grained token form with the permissions filled in. Give it only your notes repository, then paste the token. Obsidian keeps it in its secret storage.

  5. Connect, look, start.

    Click Connect, look over what the first sync will do, then click Start syncing. Repeat on each device.

Good to know
  • It's in beta, and needs Obsidian 1.11.4 or newer.
  • GitHub only, and only private repositories. GitHub can read your notes; they aren't end-to-end encrypted.
  • Files up to 8 MiB each, and vaults up to 128 MiB in total.
  • Git LFS, symlinks and submodules aren't supported.

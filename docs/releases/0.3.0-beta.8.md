# GitHub Vault Sync 0.3.0-beta.8

**Simpler.** Obsidian settings, themes and plugins always sync, so the switch to turn that off is gone. Connecting no longer reads or moves a `.git` folder in the vault; it's left alone and never synced. Enter the repository and branch yourself.

**Smaller.** About 900 lines of code for reading older journal formats are gone. Journals written by beta.1 through beta.7 still load as before.

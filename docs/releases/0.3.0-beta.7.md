# GitHub Vault Sync 0.3.0-beta.7

**Smoother on phones.** Uploads no longer decode every vault file on the main thread, base64 work is several times faster, long loops yield to the UI, unchanged settings files and journal objects aren't re-read, and independent GitHub requests run together.

**Calmer syncing while typing.** Edits sync after 30 seconds without typing (at most 2 minutes after the first edit) and right away when you leave Obsidian.

**Errors that help.** Losing the connection shows quietly as offline. Problem notices clear when sync recovers, and token or repair problems open settings. Error messages no longer show internal codes.

**Engine fixes.**
- Large first uploads (thousands of files) no longer fail on every retry, and retries skip blobs already uploaded.
- A momentarily stale branch read no longer pauses sync.
- Copies kept for deleted and replaced files are cleaned up once safely on GitHub, and safety copies expire.
- Two files differing only by capital letters show as a conflict instead of breaking sync.
- Confirming a batch of deletions isn't undone by unrelated edits.

**Updates.** A small companion plugin, GitHub Vault Sync Updater, installs new versions from the private `updates` branch using the same GitHub token, verifies checksums, and rolls back if a version fails to load.

# GitHub Vault Sync 0.3.0-beta.2

Setup now fits one screen: repository, branch, token, optional Obsidian settings, and Connect. A first-sync review leads to Start syncing. There is no fresh-vault requirement or sole-writer checkbox.

Existing ordinary Git vaults can be adopted in place. On Start syncing, the prior .git directory is moved intact into .git-vault-sync/previous-git/<id>/dot-git. Notes stay where they are. This is a point-in-time archive, not a live checkout. Active Git operations, linked worktrees and submodules prevent adoption with an explanation. Competing sync plugins must be disabled. The GitHub no-force-update protocol is unchanged.

Commit messages have editable templates, local-time date formatting and a live preview, available before the first sync. The default matches the owner's dated backup style. The old Git plugin's hostname and numFiles placeholders are also accepted.

The command palette now exposes Sync now, Sync status, Sync history and File history. Sync history lists GitHub commits across devices, pinned to this device's synced version, with dates, messages and GitHub links. Recovery and settings reviews live in their relevant screens.

Validation: 498 plugin tests pass; plugin typecheck and package build pass. Added coverage includes message formatting through an actual sync session, history pagination, setup/confirmation wiring, interrupted Git-folder adoption, and byte-for-byte preservation in a disposable real Git checkout. Native macOS Obsidian 1.13.7 loads the installed beta.2 build and renders the new settings. The revised UI has not yet been exercised on Android; previous Android evidence covers beta.1's underlying sync engine. Prior unsaved-editor and storage limitations remain.

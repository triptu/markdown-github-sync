# GitHub Vault Sync 0.3.0-beta.1

A self-contained Obsidian sync plugin for desktop and Android. GitHub holds the shared committed history; each device keeps its unpublished drafts and recovery journal. No Cloudflare service, terminal Git, or companion phone app is needed for syncing.

## Included

- Automatic foreground sync after saved changes, on foreground return and periodically, plus **Sync now**.
- Concurrent independent edits, exact-head publication, durable receipts for uncertain network responses, and reviewed recovery after branch rewrites.
- Conflict inbox with common/local/GitHub versions, either-version decisions, keep-both, and editable Markdown merges.
- Text and attachment changes, renames, deletions with bulk-deletion review, and protection against unreadable files being mistaken for deletions.
- File history, exact restore previews, and historical bytes published as a new commit.
- Reviewed settings, themes and plugin-file sync. New hidden files need publication consent; incoming configuration needs application review. Stale settings writes remain guarded across restart and after restore, while unrelated notes continue syncing.
- Supported committed `.gitignore` rules and reviewed migration from visible-only enrollment.
- Recovery browsing, hidden exports, oversize-file inspection/export and retention accounting, plus journal cleanup that preserves referenced recovery objects.
- Quint as the sole maintained specification language. Generated TLA is compiler output; the handwritten TLA+ baseline stays in Git history.

## Known limits

Two emulator journal writes produced zero-byte temporary files and failed readback verification. Sync stopped before accepting the journal write. Unchanged-code retries and a fresh complete configuration run succeeded. The cause remains unresolved; source analysis suggests a lower storage layer but does not prove that attribution. The integrity check was not bypassed or weakened. See the [investigation and parent assessment](../verification/android-zero-write-analysis.md).

Physical-phone acceptance, hardware power-loss durability and fine-grained PAT authorization were not independently exercised. The live GitHub tests used the existing CLI credential, transferred privately to Obsidian SecretStorage. Real-device timing and arbitrary third-party editor behavior are not established by emulator tests.

Files are limited to 8 MiB each and decoded snapshots to 128 MiB. LFS pointers, symlinks, submodules and unsafe paths are rejected in scope. GitHub sees readable contents. Continuous background sync is not promised: Android can suspend Obsidian. Installation requires copying three plugin files once; subsequent syncing is self-contained.

## Install and switch safely

1. Keep the original Git-backed vault and its existing plugin as the rollback copy. The real `notes` vault and repository were not modified during this work.
2. Create a separate empty vault on each device. Copy `main.js`, `manifest.json`, and `styles.css` from the release ZIP into `.obsidian/plugins/github-vault-sync/` and enable it.
3. Configure your private repository and existing branch, select a repository-scoped token in Obsidian SecretStorage, save settings, and review enrollment before confirming. The plugin refuses a vault containing `.git` or a detected competing sync plugin.
4. Confirm the downloaded notes and attachments and that the status reaches synced. New configuration additions and incoming settings may require separate review.
5. Complete one small edit in each direction on your actual phone and laptop and confirm its committed bytes on GitHub. Then use the new vaults for editing and disable the old sync plugin in the retained original vault. Do not run two sync engines over the same directory or delete the rollback vault during cutover.

The implementation and package are ready for this staged beta cutover. This release does not claim that your real vault has already been migrated.

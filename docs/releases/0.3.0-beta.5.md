# GitHub Vault Sync 0.3.0-beta.5

- Files that need a decision are listed right on the settings page, each with a **Resolve** button.
- The conflict screen shows a line diff (this device vs GitHub) instead of three full copies, with one-tap, full-width choices sized for phones.
- **Edit and combine** starts from both versions merged where they differ.
- When several files need a decision, **Keep GitHub's for all** / **Keep this device's for all** resolves them together.
- Sync status lists decisions without waiting for the full local scan; unsynced files fill in afterwards.

# GitHub Vault Sync 0.3.0-beta.4

The access-token setting now shows a compact Create token link and Copy link button. Both use GitHub's supported URL parameters to prefill the token name, description, resource owner, Contents write permission and Metadata read permission. Repository selection remains on GitHub's form because its documented template parameters do not support selecting an individual repository.

Validation: 528 plugin tests pass, TypeScript checking and package build pass. The installed desktop plugin was reloaded; the phone's plugin files were updated and checked byte-for-byte with the packaged build. Saved credentials and configuration are preserved.

Reference: [GitHub token URL parameters](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#pre-filling-fine-grained-personal-access-token-details-using-url-parameters).

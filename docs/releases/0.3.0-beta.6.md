# GitHub Vault Sync 0.3.0-beta.6

**Problems surface; success stays quiet.** A sync problem raises one notice that stays until tapped, and turns the status line red. Offline is retried quietly and only reported after 6 hours without a sync.

**Calmer screens.**
- Settings lead with sync state and anything that needs you. "Sync now" no longer competes with real actions. History, commit messages and the token sit under Advanced.
- The conflict view gives the diff the screen: this device's lines in green with a solid edge, GitHub's in blue with a dashed edge. The two main choices share one row.
- Obsidian settings review groups updates by plugin, only warns about plugins actually running here, and offers a reload after applying.
- The Local recovery screen is gone. Internal safety copies stay hidden and are pruned automatically.

**Faster on phones.** The sync journal, vault scan and GitHub blobs are no longer re-read and re-hashed on every action. The scan no longer walks the plugin's own storage or `.git`.

**Fixes.** "Sync now" during a running sync now runs again afterwards instead of doing nothing, so recorded decisions apply right away. Sync status no longer duplicates sections and refreshes after background syncs.

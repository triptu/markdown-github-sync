# GitHub Vault Sync 0.4.0

**Ready for Obsidian's community plugins.** Each release now carries `main.js`, `manifest.json` and `styles.css` as separate files, so Obsidian and BRAT can install and update the plugin. Versions are plain numbers from now on. Once the plugin is listed, Obsidian keeps it up to date and the companion updater is no longer needed.

**Updater.** It reads new versions from this public repository and needs no token.

Sync itself works as in 0.3.0-beta.8.
